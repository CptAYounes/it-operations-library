# IT Operations Library

A growing collection of practical notes, checklists, troubleshooting workflows and small tools for computer hardware, operating systems, networking and day-to-day IT operations.

The material is written as a working technical reference. It focuses on the checks that narrow a fault, the evidence worth recording, and the validation needed before calling work complete. Some procedures reflect direct hands-on practice; others are study references or reproducible lab procedures. They are not presented as production experience.

## What belongs here

- hardware selection, assembly, firmware and fault isolation
- Windows and Linux installation, administration and recovery
- TCP/IP networking and connectivity diagnostics
- host, service and log monitoring
- incident, change, patching, backup and handover practices
- concise runbooks and reusable record templates
- small, read-only diagnostic utilities in Bash, PowerShell and Python

## How to use the library

Start with the subject notes when learning or investigating an unfamiliar fault. Use the runbooks for a shorter response sequence, the checklists before or after planned work, and the templates to retain evidence and decisions.

Commands are labelled by platform where that matters. A command that is safe in one situation can still be disruptive in another, so the procedures call out authority, downtime and data-loss boundaries rather than assuming every reader has permission to make changes.

## Scope and limitations

This is a personal technical library, not a replacement for vendor documentation or an organisation's change, security and escalation policies. Examples use neutral or synthetic details and do not represent customer incidents. Hardware behaviour also varies by model and firmware; vendor service documentation takes precedence for component-specific work.

The section links will be added as each area is populated so the index always reflects material that is actually present.
