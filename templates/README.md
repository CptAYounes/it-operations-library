# Record templates

These blank records keep operational evidence and decisions consistent without implying a particular ticketing system.

- [Troubleshooting record](troubleshooting-record.md) — observations, hypotheses, actions and recovery evidence
- [Incident record](incident-record.md) — impact, timeline, response and follow-up
- [Change record](change-record.md) — scope, risk, implementation, validation and backout
- [System build record](system-build-record.md) — components, configuration and build validation
- [Shift handover record](shift-handover.md) — current state, open work and next actions

Copy the appropriate template into an authorised work location. Do not commit completed records containing customer data, credentials, private infrastructure details or unique device identifiers to this repository.
